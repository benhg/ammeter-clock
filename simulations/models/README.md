# Manufacturer models

`OPAx197.LIB` is the unmodified TI OPAx197 PSpice model, Final 1.3, 23 June 2022, extracted from https://www.ti.com/lit/zip/sboma34 on 2026-10-12. Manufacturer copyright and usage terms remain in the file. Pins: IN+, IN−, VCC, VEE, OUT. ngspice uses PSpice compatibility through ../.spiceinit.

`lmx58_lm2904.lib` is the earlier TI model from https://www.ti.com/lit/zip/snom268, retained for archived Rev C results. It is not used by Rev D.

Models represent nominal devices, not worst-case silicon, and do not validate operation below rated supply voltage.
