Native desktop setup and calibration for KN6UBF ammeter clocks on Arduino Uno R3 and R4 WiFi.

### New since v0.3.0

- Native desktop app with separate USB connection and firmware installation controls.
- R4 Wi-Fi search, password visibility, and disconnect/search/reconnect flow.
- Searchable IANA timezones, editable custom offsets, and automatic daylight-saving transitions.
- Smooth clock display and configurable 5–600 second calibration sweeps.
- Integrated R4 Wi-Fi module update to qualified version 0.6.1, guided power cycle, and restoration of clock firmware. Recovery survives restarting the app and verifies the original board and saved settings.
- More precise NTP send diagnostics and faster retry after send failures.

### Downloads and setup

Windows x64 and Linux x64 app archives are attached with SHA-256 checksums. Extract the archive and open **KN6UBF Clock Setup**. Python, Arduino CLI, and Arduino Firmware Uploader are bundled. Internet access is needed for board support and Wi-Fi firmware downloads. Linux needs desktop GUI libraries and serial-port access.

**macOS download is pending Apple notarization and is not included in this release yet.** The signed 0.6.0 app is installed on the development Mac; do not use unsigned CI artifacts as customer releases.

Use **Install / update firmware** for the R4 Wi-Fi module updater. Disconnect all power and reconnect when prompted before restoring clock firmware. Calibration settings are retained and checked when readable before the update. The app is 0.6.0; bundled clock firmware identifies as 0.5.0. R3 does not support Wi-Fi.

The browser setup page is a separate, older interface and does not include these native desktop features. Existing boards do not update automatically. New customers should calibrate their fitted meters before enabling outputs.
